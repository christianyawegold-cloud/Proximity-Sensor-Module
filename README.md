# Proximity Sensor Module (Fontys ICT Challenge 1)

## 📌 Project Overview
This project is a hardware-based proximity sensor module built for Fontys University of Applied Sciences (Challenge 1). It uses an ESP32 microcontroller to detect distance and visually output the system state using an LED strip.

## 🛠️ Hardware Components Used
* ESP32 Microcontroller
* IR / Ultrasonic Sensor
* NeoPixel LED Strip
* Breadboard & Jumper Wires

## ⚙️ System Logic
* **Safe State:** When an object is outside the 5cm threshold, the LEDs display a Green state.
* **Alert State:** When an object breaches the 5cm threshold, the system registers a hit and triggers a Red state.
